## Research & Synthesis Templates

To maintain academic rigor and structural consistency when answering the Phase 2 questions, use the following standardized templates.

*   **[Research Deep-Dive Template](templates/research-deep-dive.md)**: A structured markdown template for conducting exhaustive literature reviews, technical breakdowns, and architectural analysis for any of the Phase 2 questions.
*   **[Synthesis Report Template](templates/synthesis-report.md)**: Designed for aggregating findings across multiple related questions to produce high-level executive summaries and strategic recommendations.
*   **[Source & Literature Tracker](templates/source-tracker.md)**: A tabular template to log academic papers, patents, code repositories, and empirical benchmarks referenced during your research.

## How to Use This Hub

1.  **Review Phase 1**: Start by reading the documents in the `answers/` directory to build a solid foundation on the current state of the art.
2.  **Select a Phase 2 Question**: Choose a question from the Phase 2 table that aligns with your current research objectives.
3.  **Initialize the Research File**: 
    *   Copy the contents of `templates/research-deep-dive.md`.
    *   Create a new file in the `questions/` directory matching the target link (e.g., `questions/21-causal-reasoning.md`).
    *   Paste the template and begin your research.
4.  **Track Sources**: Use the `templates/source-tracker.md` to maintain a clean bibliography of peer-reviewed papers, GitHub repositories, and technical specifications.
5.  **Synthesize**: Once multiple related questions are answered, use the `templates/synthesis-report.md` to compile cross-disciplinary insights.
